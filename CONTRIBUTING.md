# Contributing

Contributions are welcome, but every contributor must first accept the
Contributor Agreement in [`.github/CLA.md`](.github/CLA.md). By accepting it,
you agree that rights in your contributions are transferred to Peter Jaeckel
to the extent permitted by law, with the alternative rights grant described
there applying where a transfer is not legally possible.

Pull requests must not be merged until all contributors have completed the
agreement through the repository's configured CLA Assistant integration.
The repository owner must install and configure the CLA Assistant GitHub App
to use [`.github/CLA.md`](.github/CLA.md); without that setup, signature
collection is not automatically enforced.
Contributors must have the authority to make that agreement and must identify
any third-party material included in a contribution.
